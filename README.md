# 엘크루 관리비 — Home Assistant

아파트 관리비(vnrisa), 도시가스(GSE), 음식물쓰레기(citywaste RFID 종량기), 코콤(코콤 홈매니져)
네 출처를 하나의 통합으로 묶어 "엘크루 관리비" 기기 하나에서 관리하는 커스텀 컴포넌트입니다.

## 기능

### 관리비 (vnrisa, 링크 붙여넣기)
- v.vnrisa.com 고지서는 매달 바뀌는 Token이 카카오 알림톡으로만 오고 예측·재사용이 불가능해
  자동 조회가 불가능합니다. 그 달의 고지서 링크를 **"고지서 링크" 텍스트 입력창에 그대로
  붙여넣으면** 즉시 조회해서 센서에 반영합니다.
- 고지서의 **모든 항목을 항목명 하드코딩 없이 자동으로 센서화** (새 항목이 생기면 자동 추가,
  선거관리운영비처럼 어쩌다 한 번만 나오는 항목도 history에 남습니다)
- 각 센서 속성에 **월별 history** 누적 — 과거 달 링크를 나중에 넣어도 현재 표시값은
  그대로 두고 history에만 추가됩니다
- 재시작해도 마지막으로 성공한 링크로 자동 재조회되어 센서가 비지 않습니다

### 도시가스 (GSE, 로그인 기반)
- 아이디/비밀번호 로그인으로 **최근 24개월치** 고지·수납 내역을 한 번에 조회(GSE가 범위 지정
  조회를 지원해서 음식물쓰레기처럼 달마다 따로 긁을 필요가 없음)
- 가스 사용량 · 청구금액 · 납부금액(미납 여부/수납일 포함) · 계량기 지침 — 4개 다 history는
  **최근 12개월**로 유지(그 이상은 "작년" 비교에도 안 쓰여서 계속 안 쌓아둠)
- **하루 1회** 지정 시각에 자동 재조회 (기본 09:00, 옵션에서 변경 가능)

### 음식물쓰레기 (citywaste RFID 종량기, 로그인 기반)
- 아이디/비밀번호 로그인으로 "나의 수수료 조회" 월별 정산내역 조회
- **배출량 / 배출건수 / 최근 배출량** — 기기 카드 상단에 바로 표시되는 대표 센서 (이번 달은
  아직 정산 배치가 안 돌아 0으로 나오는 citywaste 자체 한계를 피하려, 로그인 없이도 되는
  실시간 조회 API로 이번 달분만 덮어써서 항상 "지금까지" 값을 보여줍니다). **최근 배출량**은
  가장 최근 한 건(dttime 기준)의 kg만 보여주는 거라 "지난달" 개념이 없어서, 다른 사용량
  센서들과 달리 history를 여러 달 안 쌓고 이번 달 것만 유지합니다
- **정산금액 / kg당 단가**(단가조회 팝업 기준)는 진단 섹션으로
- 설치 후 **한 번도 조회에 성공한 적이 없으면** 최근 **12개월치**를 한 번에 백필 (이미 백필했으면
  옵션에서 로그인을 다시 입력해도 재백필하지 않음) — 그 뒤로는 **매달 1일 확인시각**(`HH:MM`, 기본
  09:00, 옵션에서 변경 가능)에 지난 달 1개월(정산내역 페이지)만 가볍게 갱신 (정산 배치 전이라 늘
  0원인 이번 달 정산 페이지는 애초에 긁지 않음)
- 이번 달 배출량/배출건수/최근 배출량은 그 월 1회 갱신과는 별개로, 로그인이 필요 없는 실시간
  API만 **실시간 조회주기**(기본 1800초=30분, 옵션에서 변경 가능)마다 따로 더 자주 갱신

### 코콤 (코콤 홈매니져, 아파트 단지 로컬 월패드)
- 단지 월패드 서버에 아이디/비밀번호로 **로그인**하고(코콤 아이디로 서버 주소 자동 조회),
  그 뒤로는 자체 소켓 연결을 유지하며 **실시간 조회주기**마다 자동 폴링 (기본 1800초=30분,
  설정 시 변경 가능) —
  GSE/citywaste처럼 매번 새로 로그인하는 방식이 아니라, 로컬 소켓이라 Token 문제 없이 계속
  붙어있는 구조
- **전기 사용량 / 가스 사용량 / 수도 사용량** — 실시간 이번 달 사용량, 기기 카드 상단에 바로 표시되는 대표 센서
- **전월사용량 / 작년사용량**(각 사용량마다 하나씩) — 위 사용량과 같은 레벨의 독립 센서로,
  history 속성 대신 대시보드/그래프/자동화에서 바로 쓸 수 있게
- 그 외(조회시각 등)는 진단 섹션으로

### 공통
- vnrisa/GSE/citywaste 쪽 센서는 전부 **진단** 섹션으로 내려가고(음식물쓰레기 배출량/배출건수
  제외), 이름이 겹치는 항목(예: "전기 사용량"이 코콤/vnrisa 양쪽에 있음)은 출처 태그
  `(vnrisa)`/`(GSE)`/`(citywaste)`/`(kocom)`를 붙여 구분합니다
- vnrisa/GSE/citywaste 각각 **조회시각** 진단 센서 제공 — 조용히 조회가 실패하고 있어도
  바로 확인 가능 (코콤은 "코콤 조회시각"이 같은 역할)

## 설치

### HACS
HACS → 사용자 지정 저장소 → `https://github.com/kshexe/elcru_bill` 추가 (유형: Integration) →
설치 → HA 재시작.

### 수동
`custom_components/vnrisa_bill` 폴더를 `config/custom_components/`에 복사 후 재시작.

## 설정
설정 → 기기 및 서비스 → 통합 추가 → **엘크루 관리비**

1. **도시가스(GSE) 로그인** — 아이디/비밀번호 (로그인 검증까지 진행)
2. **코콤(코콤 홈매니져) 계정** — 아이디/비밀번호만 입력하면 됩니다. 서버 주소는 입력 없이 아이디로 자동
   조회해서 인증까지 한 화면에서 끝나고, 실시간 조회주기는 여기서 묻지 않고 기본값
   (1800초)을 그대로 씁니다 - 바꾸고 싶으면 설치 후 옵션의 "코콤 설정"에서 조정하세요.

3. **음식물쓰레기(citywaste) 추가** (설치 후, 옵션의 **"음쓰 설정"**에서) — 아이디/비밀번호 +
   태그인쇄번호/동/호(citywaste.or.kr "나의 수수료 조회" 페이지에서 확인 가능)를 전부 직접
   입력하면 그때부터 추가됩니다(로그인 검증 + 최근 12개월 백필까지 한 번에 진행). 실시간
   조회주기(기본 1800초)와 지난달 확인시각(기본 09:00)은 이 화면에서 바로 바꿀 수 있습니다 -
   가스/코콤과 달리 citywaste는 "최초 설치"와 "옵션" 화면이 분리돼 있지 않고 이 옵션 화면이
   유일한 설정 지점이기 때문입니다.

생성 후 **"고지서 링크"** 텍스트 엔티티에 그 달 관리비 고지서 링크를 붙여넣으면 관리비 센서들이
채워집니다.

### 옵션
설정에서 통합의 "옵션"으로 들어가면 네 가지 메뉴가 **관리비 → 도시가스 → 음쓰 → 코콤** 순으로
있습니다.
- **관리비 설정** — vnrisa는 로그인/고정 주기가 없어서 안내만 하는 화면
- **도시가스 설정** — 아이디/비밀번호 + 확인시각(`HH:MM`, 기본 09:00)을 한 화면에서
- **음쓰 설정** — 아이디/비밀번호 + 태그인쇄번호/동/호를 전부 직접 입력(자동 추출 없음) +
  실시간 조회주기(초, 기본 1800) + 확인시각(`HH:MM`, 기본 09:00)
- **코콤 설정** — 아이디/비밀번호 + 실시간 조회주기(초, 기본 1800)

(컴포넌트 안에서는 "음쓰"로 짧게 표시되고, 이 문서에서만 풀어서 "음식물쓰레기"로 적었습니다.)

## 주의
비공식 프로젝트이며 관리비(vnrisa) / 도시가스(GSE) / 음쓰(citywaste) / 코콤과 관련이 없습니다. 각 사이트/프로토콜의
페이지 구조나 소켓 포맷이 바뀌면 파싱·인증이 실패할 수 있습니다.
