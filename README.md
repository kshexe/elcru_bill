# 엘크루 관리비 — Home Assistant

아파트 관리비(vnrisa), 도시가스(GSE), 코콤 월패드 에너지, 음쓰(citywaste RFID 종량기)
네 출처를 하나의 통합으로 묶어 "엘크루 관리비" 기기 하나에서 관리하는 커스텀 컴포넌트입니다.

## 기능

### 코콤 에너지 (월패드 로컬 소켓, 자동 폴링)
- **전기 사용량 / 가스 사용량 / 수도 사용량** — 실시간 이번 달 사용량, 기기 카드 상단에 바로 표시되는 대표 센서
- 그 외(응답시각 등)는 진단 섹션으로
- 아파트 단지 로컬 월패드 서버에 직접 붙는 방식이라 Token 문제 없이 주기적으로 자동 폴링 (기본 1시간, 설정 시 변경 가능)

### 도시가스 (GSE, 로그인 기반)
- 아이디/비밀번호 로그인으로 **최근 24개월치** 고지·수납 내역을 한 번에 조회
- 가스 사용량 · 청구금액 · 납부금액(미납 여부/수납일 포함) · 계량기 지침
- **하루 1회** 지정 시각에 자동 재조회 (기본 09:00, 옵션에서 변경 가능)

### 관리비 (vnrisa, 링크 붙여넣기)
- v.vnrisa.com 고지서는 매달 바뀌는 Token이 카카오 알림톡으로만 오고 예측·재사용이 불가능해
  자동 조회가 불가능합니다. 그 달의 고지서 링크를 **"고지서 링크" 텍스트 입력창에 그대로
  붙여넣으면** 즉시 조회해서 센서에 반영합니다.
- 고지서의 **모든 항목을 항목명 하드코딩 없이 자동으로 센서화** (새 항목이 생기면 자동 추가,
  선거관리운영비처럼 어쩌다 한 번만 나오는 항목도 history에 남습니다)
- 각 센서 속성에 **월별 history** 누적 — 과거 달 링크를 나중에 넣어도 현재 표시값은
  그대로 두고 history에만 추가됩니다
- 재시작해도 마지막으로 성공한 링크로 자동 재조회되어 센서가 비지 않습니다

### 음쓰 (citywaste.or.kr RFID 종량기, 로그인 기반)
- 아이디/비밀번호 로그인으로 "나의 수수료 조회" 월별 정산내역 조회
- **배출량 / 배출건수** — 기기 카드 상단에 바로 표시되는 대표 센서 (이번 달은 아직
  정산 배치가 안 돌아 0으로 나오는 citywaste 자체 한계를 피하려, 로그인 없이도 되는
  실시간 조회 API로 이번 달분만 덮어써서 항상 "지금까지" 값을 보여줍니다)
- **정산금액 / kg당 단가**(단가조회 팝업 기준)는 진단 섹션으로
- 처음 설치/옵션 저장 시 **최근 12개월치**를 한 번에 백필하고, 그 뒤로는 **매달 1일 00:00**에
  최근 2개월만 가볍게 갱신 (이미 끝난 달 정산내역은 그 뒤로 안 바뀌어서 매일 다시 긁지 않음)

### 공통
- vnrisa/GSE/citywaste 쪽 센서는 전부 **진단** 섹션으로 내려가고(음쓰 배출량/배출건수 제외),
  이름이 겹치는 항목(예: "전기 사용량"이 코콤/vnrisa 양쪽에 있음)은 출처 태그
  `(vnrisa)`/`(GSE)`/`(citywaste)`를 붙여 구분합니다
- vnrisa/GSE/citywaste 각각 **마지막 조회 시각** 진단 센서 제공 — 조용히 조회가 실패하고 있어도
  바로 확인 가능

## 설치

### HACS
HACS → 사용자 지정 저장소 → `https://github.com/kshexe/elcru_bill` 추가 (유형: Integration) →
설치 → HA 재시작.

### 수동
`custom_components/vnrisa_bill` 폴더를 `config/custom_components/`에 복사 후 재시작.

## 설정
설정 → 기기 및 서비스 → 통합 추가 → **엘크루 관리비**

1. **도시가스(GSE) 로그인** — 아이디/비밀번호 (로그인 검증까지 진행)
2. **코콤 아이디** — 단지 월패드 서버 IP를 자동으로 조회
3. **코콤 계정** — IP(자동 채워짐)/아이디/비밀번호 + 폴링 주기(초, 기본 3600)

생성 후 **"고지서 링크"** 텍스트 엔티티에 그 달 관리비 고지서 링크를 붙여넣으면 관리비 센서들이
채워집니다.

음쓰(citywaste)는 최초 설치 흐름에는 없고, 설치 후 옵션의 **"음쓰 로그인"**에서 아이디/비밀번호를
입력하면 그때부터 추가됩니다(로그인 검증 + 최근 12개월 백필까지 한 번에 진행).

### 옵션
설정에서 통합의 "옵션"으로 들어가면 다음을 바꿀 수 있습니다.
- **도시가스 확인시각**(`HH:MM`, 기본 09:00)
- **도시가스 로그인** / **코콤 에너지 로그인** / **음쓰 로그인** — 비밀번호가 바뀌었을 때 재입력

## 주의
비공식 프로젝트이며 vnrisa / GSE 도시가스 / 코콤 / citywaste와 관련이 없습니다. 각 사이트/프로토콜의
페이지 구조나 소켓 포맷이 바뀌면 파싱·인증이 실패할 수 있습니다.
